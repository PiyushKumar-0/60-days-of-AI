How this was researched

Manufacturer pages were used for official configurations, India pricing, storage and weight where available. Notebookcheck independent reviews were used for comparable Wi-Fi battery tests.

PriceOfficial India-listed prices are used where available. Prices can change.
BatteryIndependent Wi-Fi measurements are used instead of mixing manufacturer “up to” claims.
PortabilityLower device weight is treated as better.
StorageBase configuration storage is compared.

Scoring: each criterion is normalized between the best and worst observed value, then multiplied by the user's normalized weight. The result is a transparent derived score, not a reviewer rating.

Conflict handling: manufacturer battery claims can differ from independent tests. Independent testing is used for the battery score because it is directly comparable.
